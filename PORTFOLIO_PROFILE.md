- Dedicated supervisor module for oversight and approvals
- Real-time progress tracking for maintenance and project activities
- Generates status, on-hold, descope and detailed performance reports

### Noor Shop

Cross-platform e-commerce mobile app; the frontend was built solo. The site's chatbot marks it "In Progress".

- JWT authentication with secure token storage
- Product browsing with search, filters and category navigation
- Product variations: size, color and quantity selection
- Cart management and Stripe payment integration
- Order history and push notifications
- Performance work: FlatList pagination, minimal animations, WebP images from the backend

### HIFZ Tracking

Web app for tracking Quran memorization (Hifz) progress and managing students. Saad built the React frontend; the Node.js backend was provided.

- Voice feature for submitting recitations

- Real-time notifications and updates

### Food Recipe

React Native recipe app for iOS and Android.

- Welcome, Home and Recipe Details screens

### Final Year Project

- Real-time messaging using WebSockets

### Chatz

### Umrah Portal

### POS System

Desktop point-of-sale system built with React Native Windows.
